# Mattermost

Posts alerts to Mattermost via an **incoming webhook** with attachment payloads.

## Setup

1. Create an incoming webhook in Mattermost; copy the URL.
2. Admin → Integrations → Mattermost → Install.

## What leaves EmailBridge

Subjects and account fields in the attachment map are delivered to your Mattermost server.

Switch: `integrations.mattermost`.
