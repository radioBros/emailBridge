# SDKs

Client SDKs for Go, TypeScript, PHP and Python: API client, Standard Webhooks signature verification and an
SSE event-stream helper. Each SDK has a quick start in its README.

| Language | Package | Install | README |
| --- | --- | --- | --- |
| Go | `github.com/radiobros/emailbridge/sdk/go` | `go get github.com/radiobros/emailbridge/sdk/go@latest` | `sdk/go/README.md` |
| TypeScript | `@emailbridge/sdk` | `npm install @emailbridge/sdk` | `sdk/typescript/README.md` |
| PHP | `emailbridge/sdk` | `composer require emailbridge/sdk` | `sdk/php/README.md` |
| Python | `emailbridge` | `pip install emailbridge` | `sdk/python/README.md` |

Any other language can use the OpenAPI document ([API](../api/index.md)) and a Standard Webhooks library.
